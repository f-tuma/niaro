# Roadmap

Goal: Fix the regressions and member-visible bugs found by the live dev-server test of the Pi Durable agent core (2026-11-12, NIAR-307), so chat, approvals, the process designer and old chats work at least as well as in the Mastra era.
Out of scope: deploy and production (the owner deploys); the wave-3/OpenSpec cleanup and the `mastra-*.ts` rename (separate step 2 of the plan); the service-catalog CPU hotspot (`service-catalog.ts:16 dto`); NIAR-306 async tasks/multiplayer; new features.

Rules for every step: commits start with `NIAR-307`, no Claude attribution; members never see internal states; sent text never returns to the composer; models only via admin providers; breaking changes allowed. `apps/server-identity/agent-runtime.ts` is the legacy runtime (only `catalog-runtime-legacy.ts` loads it): do not fix the live path there. QA reports with repro and evidence: `/tmp/claude-1000/qa-pi/` (`chat/REPORT.md`, `proc/REPORT.md`, `report.md`, `review-report.md`, mobile: `done-body.txt`). Dev server: tmux `niaro-dev`, https://aa.f-tuma.dev, see memory note `dev-server-and-orca-browser.md`. Pre-Pi data backup: `.identity.backup-pre-pi-20261112-231616/` (read-only).
