# Pet pages as a little device (Tamagotchi-style) — design bundle

Status: **proposal** (2026-11-01). Research + design brief for reworking the
mobile and web pet pages; no production code changed.

- `research.md` — what the Tamagotchi/companion-app presentation does, what to
  borrow without gamification, accessibility notes, sources.
- `brief.md` — the recommended design: control map, mobile/web wireframes,
  tokens, icons, motion, copy (CS/EN), open questions.
- `concept.html` — static mock: open the file in a browser (no build, Google
  Fonts optional). Shows mobile overview, section screen, off/empty screens,
  desktop overview and desktop section view.
- `concept-render.png` — headless Chromium render of `concept.html` (verification only).
