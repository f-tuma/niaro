# Mobile Pet design inventory before prototype

This is a new proposal, not aesthetic acceptance or a production implementation. The three ImageGen screens establish one direction; exact canonical assets and native typography take precedence over image-generation drift. Concept paths: concepts/01-overview-dark.png, 02-memory-dark.png, 03-appearance-light.png (853×1844 each; logical390×844).

- Overview: native back/title/appearance header, Poznatky/Uložené/O tobě tabs, Pracovní + Paměť row, centered260px pet canvas, Bublina, six52px section buttons in logical Práce/Projekty/Nástroje/Lidé/Styl/Rytmus order. No count, greeting, extra description, composer or fourth navigation item.
- Memory detail: same header/tabs, centered retained160px pet, Všechny oblasti, Styl, two readable statements; first expands source/date/seenAt and Opravit/Smazat. Pet stays central and gives space to detail. Ordinary button navigation and restored focus, no gesture interception.
- Appearance: own back header, centered240px pet, Bublina, Vzhled group (Jméno, Pohyb peta, Zobrazit v chatu), Prostředí group (Motiv, Počasí). Theme proposed for mobile; dark remains current native default. Weather opens context-only source choices and never requests location.
- Palette: current native dark #141518 / #F4F4F6 / #A3A7B2 / #35373E / #9AAFFF. Light proposal uses approved web #fff / #1c1d21 / #656A75 / #E1E3E8 / #3659cf. Exact pet stills retained; their dark backdrop is #131416, a1RGB-unit delta from tokens, intentionally not edited or tinted.
- Typography: actual Manrope, header20/28 weight600; body17/25; controls15/22; metadata13/20; pet name20/28. Root-font scaling drives all text. Single native-like64px-min header; content can expand. No fixed heights for text.
- Geometry:20px content gutter;12px header gutter; minimum48px actionable targets (existing native44dp is lower bound); control radius12px, 1px hairlines, no nested cards, no outside glow, no new logo, shape or mascot. Native title will be left aligned after back per actual ScreenChrome (intentional correction to centered generated header).
- Inputs/assets: unchanged pet-dark.png/pet-light.png, unchanged official logo.svg, unchanged pet-nav-icon.svg and Manrope. Prototype uses static pet and no invented C2 engine approximation; real tap/stroke/hold remain reserved. No motion/render performance claim.
- At320px or enlarged text, sections become a single column if labels cannot fit; tabs wrap; scope row stacks; pet remains central. One document scroller, no fixed header obscuring focus, no ellipsis on memory statements. Appearance row labels/values stack when needed.
- All content is synthetic owner-relative demo data; local state only. Correction moves inferred data to saved owner assertion; off/plugin-off omits correction but retains inspection/erase. Actual memory200-row cap/no cursor remains a release gap, not a fabricated Load more.
