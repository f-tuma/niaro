## Method and actual results

Linux/amd64 kernel 7.3.0-4-cachyos, Docker 29.9.2, rootful cgroup v2. Only named disposable test projects ran, with no app/emulator, S3/RustFS, provider, customer files or unrelated service/container inspection. The services had no runtime socket. Worker limits actually recorded: **536,870,912 memory bytes, same memory+swap ceiling (no swap), one CPU quota, 64 PIDs, read-only root, network none, only SETUID/SETGID/SYS_CHROOT setup capabilities, no-new-privileges; 256 MiB/4096-inode noexec/nosuid/nodev scratch**. Gate dropped parser credentials/groups, closed descriptors and installed the copied reviewed policy before executing the fixed adapter. Offline MarkItDown/PDFium, python-docx/openpyxl/python-pptx and Tesseract ces+eng/OSD worked inside that boundary.

Each q3 case used the same serialized single-slot service, a changed worker epoch after PID1 exit, completed local result-file write before ACK (no file/directory fsync; crash durability untested), and 10.2 seconds idle between attempts. This verifies that narrower harness sequence, not the proposed production durable epoch counter, app-owned result commit or ten-second startup gate. Wall measurements include submit/status/restart observation and exclude the intentional idle. Processes are cold, host cache was not flushed. Values are single observations, not distributions or a latency/throughput guarantee. Memory is the highest observed cgroup `memory.peak` before old cgroup loss; a final unsampled tail may be missed, though the hard 512 MiB limit remains enforced.

## Limits and honest failure boundary

Proposed additional worker budget is 512 MiB/no swap, one CPU, 64 PIDs, 256 MiB/4096-inode scratch, 120 s attempt wall time, 2 MiB encoded result/1 MiB text, bounded sources/tables/cells and fixed ledger files. This retains the former measured 512 MiB worker envelope; observed 100-page scan time leaves margin below 120 seconds for that fixture only. Photo 12 MP comes from the previous measured 12 MP probe, with explicit header admission now checked by the 13 MP rejection. PDF raster 8 MP/page and 250 MP aggregate admit these representative scans while bounding aggregate work; these are reviewed proposed ceilings, not a guarantee based on worst-case measurements. The 64 MiB native-file/Office expansion ceilings require final enforcement and representative compatibility tests; they are not implied by compressed input size. Keep 25 MiB originals and 100-page/100-slide feature maxima. Do not reduce app 2 GiB or its charged 512 MiB tmpfs, add a pool, infer a 4 GiB host minimum, or assume two-core responsiveness.

**Precise remaining support failure:** the research adapter cannot meet the production source/coverage contract unchanged. PDF text is preserved but PDF tables are not mapped into structured table cells; all PDF results conservatively warn partial/layout unverified. DOCX covers body paragraphs/tables, with nonbody content unqualified; PPTX native shapes/tables are basic and pictures are explicitly omitted. Workbook dates, caches, merged cells, advanced formatting/relationships, nested slide shapes, annotations/forms and complex mixed PDFs still need bounded coverage detection and accepted fixtures. A source marker and matching strings alone do not prove complete reading. These are task 5.2/G5 blockers to claiming mandatory support, not grounds to erase a required format or call MarkItDown alone sufficient.

The 109.705-second text failure exposes repeated whole-object JSON checks during construction; production must use the bounded streaming encoder/validator in decision 4. q3/q4 use base64 framed JSON and schema-1 arrays/raw values, not the production binary DTO. Their shared output cap also differs from the final 64 KiB stderr contract. Final strict duplicate-key/depth/count/cell/source validation, app reservations and lineage, durable epoch counter, peer authentication, corruption/full-disk handling and native file limit are unimplemented. No production security/termination/recovery pass is claimed from the format experiment. Earlier controlled feasibility fault evidence remains attributed to its own immutable subject.
