## Merged behavior in my own words

A selected file is uploaded under an authenticated, generation-bound draft before the person presses Send. Selection and passive status recovery do not send a chat request. A negotiated attachment send commits the visible user message, immutable file bindings, ingestion/attempt, accepted receipt, history/events and the user-text memory reference in the same workflow transaction. Without processing, it remains explicitly blocked and returns before ordinary model routing; the caption cannot become a separate chat inference request. The original stays downloadable under current authority. A lost command response requires the same explicit command retry; refresh/reconnect does not resend it.

Memory learning consumes the person's persisted user text through a minimal source index. It does not consume attachment bytes, names, assistant output or service bodies. Rollover moves the public locator while preserving source identity/digest and native turn identity, invalidating a captured old locator revision. Clearing the reusable main chat erases its current generation without erasing an earlier archive. Deletion marks the correct source unavailable and denies file access before asynchronous erasure. Saved learned observations have their own accepted encrypted/privacy lifecycle; deleting a source marks provenance removed rather than implicitly forgetting every learned observation.

The dormant native handoff/publication seam uses the existing native engine, catalog sidecar and budget owners. The assistant-only publication primitive cannot append another user source or command receipt. Passive outcome reads use the exact immutable attachment alias binding and pinned outcome; they do not resume inference. Purge addresses the tombstoned ownership generation and exact native bindings, leaving a fresh fixed-chat generation intact. Unknown work is not assumed never dispatched merely because a native row is absent.

Client recovery retains the ordered file intent and exact uncertain mutations, preserves draft/scoped ownership, and distinguishes a validated terminal reference refusal from uncertainty. File Retry recovers pins without sending; initial Again can send once only if its captured caption/scope still owns the action. Web mentions are restored before pinning, with later edits owning the draft. Mobile new/current draft targeting and independent Composer `sendBlocked` preserve editable text and the existing quiet composer/pet structure. Other accepted UI/Meetings/branding/storage foundation paths were preserved by byte comparison. Final native visual/device evidence is separately owned by Astra.

Package changes are additive: the existing dependency versions remain, four reviewed Expo packages are added, both memory script registrations append suites, and a conversion test script is added.
