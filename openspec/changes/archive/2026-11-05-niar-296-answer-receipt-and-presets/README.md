# niar-296-answer-receipt-and-presets

Under every answer on the web and the phone, a quiet line built from the server's records shows what the answer read and changed, the memories, skills, meetings and files in its context and which model wrote it (and why, after a fallback or an escalation), only with items the person can open. Administrators may offer members model presets, each a named tier, off by default and never beyond the workspace's policy or budgets (NIAR-296).
