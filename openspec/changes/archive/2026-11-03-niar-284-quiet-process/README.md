# niar-284-quiet-process

A process start, answer or approval decision whose outcome was lost no longer shows "Not confirmed — it may have started" or "Not confirmed. Retry sends the same answer.": the client checks it by itself in the background by posting the identical command, and the started run, the accepted answer or the decision simply appears; only a failure the client knows of shows an ordinary failed state with Try again. Nothing is started, answered or decided twice (NIAR-284, following NIAR-280).
