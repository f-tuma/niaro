# niar-263-visible-replies

The model sees its own earlier answers in the same chat, generated UI included, also when the person has saved memory or the pet has learned something. An answer is withheld only when a saved item it drew on was forgotten, revised, expired or became unreadable, or a service result it drew on lost access. A fresh thread starts with the assistant's replies that pass, not only the person's messages (NIAR-263).
