# niar-302-agent-core-on-pi

Niaro's agent core moves from Mastra to Pi Durable in four waves (NIAR-302 foundation, NIAR-303 processes, NIAR-304 chat, NIAR-305 removal of Mastra and libSQL), for the simplest reliable stack: one language, one process, one database driver (`node:sqlite`), one agent core and one path to models.
