# niar-298-workspace-knowledge

Workspace knowledge: a derived, rebuildable libSQL vector index over the files people send in chats and the read actions an administrator picks, with access labels on every passage, a re-check of every hit against the asker's current identity and access, an agent search tool and cited passages under answers. The embedding model is the `embedding` role of the model policy; without it there is no index. Never a document store (NIAR-298).
